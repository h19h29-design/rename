# Third-party components

RE:NAME uses the Python runtime / standard-library tkinter, Tcl/Tk, lxml (and its bundled XML libraries), pywin32 on Windows, and PyInstaller for packaging. Their original copyrights and licenses remain applicable.

The Windows build copies available installed-package license files into `licenses/`. PyInstaller also bundles its required runtime components. No third-party license is replaced by this document. No font files are included in the source distribution; the interface uses fonts installed on the user's computer.
