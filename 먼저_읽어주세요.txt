이 ZIP은 소스 패키지입니다. 이미 빌드된 EXE는 들어 있지 않습니다.
빌드된 EXE는 릴리스 v0.1.0-build.1.1에서 받을 수 있습니다.

[지금 Windows에서 실행]
1. Python 3.12 64비트를 python.org 공식 배포본으로 설치합니다.
   설치 옵션의 Python Launcher와 Tcl/Tk를 포함하세요.
2. ZIP을 전부 풉니다.
3. START_WINDOWS.cmd를 두 번 누릅니다.
   첫 실행에는 패키지 다운로드를 위한 인터넷 연결이 필요합니다.
   프로그램에서 처리하는 문서는 외부 서버로 전송하지 않습니다.
4. 파일 추가 → 항목 선택 → 개인정보 탐지 → 대체값 검토 → 새 파일 저장.

[EXE 만들기]
BUILD_WINDOWS.cmd를 실행합니다.
Windows 테스트와 패키징에 성공하면 dist/RENAME-Windows-x64.zip이 생성됩니다.
배포 ZIP 전체를 풀고 RENAME/RENAME.exe를 실행하세요.
2026-09-13 Windows 11 x64 / Python 3.12.10 / PyInstaller 6.22.3에서 빌드·GUI 스모크를 통과하고 로컬 ZIP을 생성했습니다.

[형식]
XLSX/HWPX: 해당 Office 설치 없이 처리.
XLS: 설치된 Microsoft Excel을 통해 XLSX로 변환.
HWP: HWPX 저장을 지원하는 설치된 한글을 통해 HWPX로 변환.
원본 형식 HWP로 다시 저장하는 기능은 없습니다.

[주의]
원본은 보존합니다. 결과는 새로운 폴더와 파일에 저장합니다.
이름 자동 탐지는 완전하지 않아 직접 이름 추가와 최종 검토가 필요합니다.
금액/일반 날짜는 기본 OFF입니다.
이미지·서명·도장·스캔본 안 글자는 지우지 않습니다.
엑셀 결과는 공유용 복사본이며 수식은 저장된 결과값으로 바뀝니다.
차트·피벗·매크로·첨부 개체·변경 이력은 차단합니다.
